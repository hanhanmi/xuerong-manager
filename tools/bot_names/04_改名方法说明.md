# CS2 人机名字：到底改哪个文件、怎么改

> 只改名字，不动任何其它逻辑。全文以 **2026-11-14 最新版 CS2BotImprover 包**为实测对象。

---

## 一、名字在哪里

人机名字**不在插件里**，而是集中在一个文本数据库里：

```
overrides/botprofile.vpk            ← 实际被 gameinfo.gi 挂载的那份
overrides/High/botprofile.vpk       ← 困难
overrides/Medium/botprofile.vpk     ← 中等
overrides/Low/botprofile.vpk        ← 简单
        └── 每个 vpk 内部有一个条目： botprofile.db   ← 名字全在这个文本里
```

（有的模组工具还会在 `overrides/High|Medium|Low/` 旁边额外放一份**裸露的** `botprofile.db`，两边名字要保持一致。）

`botprofile.db` 每个档案块长这样，**名字就是末尾引号里的字符串**：

```
ProSlow+SniperPro+SniperPersonality "Zhang Weiwei"
    VoicePitch = 87
End
```

- 新版实测：每个 vpk 里有 **7 个条目**（`botprofile.db` + 6 个 AI 行为树 `scripts/ai/**/bt_*.kv3`），
  其中 `botprofile.db` 为 **1711 个档案**、64 种模板链、UTF-8 **无 BOM**、**LF** 换行（无 CRLF）。
- 除名字外的一切（注释、VoicePitch/LookAngle/ReactionTime、模板、行为树 kv3、条目顺序）都**不能动**。

---

## 二、只改名字的两条规则

**1) 定位（只认整行就是"模板链 + 带引号的名字"这种行）**

```regex
^([A-Za-z0-9_]+(?:\+[A-Za-z0-9_]+)*)[ \t]+"([^"]*)"[ \t]*$
```

行尾可能带 `\r`（本版没有），匹配时按 `\r\n | \n` 拆行即可。

**2) 替换**

- 按**出现顺序**，把第 i 个档案的名字换成清单里的第 i 个名字（清单见 `01_人机名字清单_1969.txt`，一行一个）。
- 档案数 < 名单数（本版 1711 < 1969）时：多出来的 258 个名字用**整块克隆**的方式追加到文件末尾 —— 复制一个完整档案块（`模板链 … End`），只把其中的名字换掉，参数/模板沿用原档案。这样 1969 个名字全部用上。
- 档案数 > 名单数时：循环使用清单（`names[i % len(names)]`），保证每个 bot 都有名字。

**名字写入前必须清洗**（否则会破坏 KV 解析或显示成方块）：

| 处理 | 原因 |
|---|---|
| 去掉 `"` | 会把 KV 的字符串提前闭合 |
| 去掉 `\` | 反斜杠是转义符（如 `99\`、`toby \3`） |
| 去掉控制字符、首尾空白 | 文件名/显示异常 |
| 去掉码点 > U+FFFF 的字符（4 字节 emoji） | CS2 字体渲染成方块 |
| 去重 | 同名 bot 看着假 |

原始名单 2000 条 → 清洗去重后 **1969 条**（`02_名字池_原始2000.txt` 是原始版本，供对照）。

## 三、VPK 重新打包（关键，改完 db 必须重新封包）

本版这类 `botprofile.vpk` 是 **Source 2 VPK v2 + 全部数据内联**（目录条目 `archiveIndex = 0x7FFF`），
文件布局：

```
[28 字节头] [目录树 tree] [数据段 data] [其它MD5块 48 字节]
```

细则（照抄即可，参考实现见 `03_改人机名字_参考脚本.py`）：

1. **头部**：`struct("<7I")` = `signature=0x55AA1234, version=2, treeSize, dataSectionSize, archiveMD5SectionSize(本版=0), otherMD5SectionSize(48), signatureSectionSize(0)`
2. **目录树**：三层嵌套，每层都是 `字符串\0`，空字符串表示该层结束：
   - `extension\0` → `directory\0` → `filename\0` → 18 字节条目
   - 根目录写成单个空格 `" "`
   - 条目 = `struct("<IHHII")` `crc32, preloadBytes=0, archiveIndex=0x7FFF, entryOffset, entryLength`，紧跟 `u16 0xFFFF` 结束符
   - `entryOffset` 是**相对数据段起点**的偏移（内联条目）
3. **数据段**：把各条目内容按条目顺序平铺（本脚本按 扩展名→目录→文件名 聚簇，与官方包一致）
4. **其它 MD5 块（48 字节 = 3×16）**：
   - `md5(tree)`
   - `md5(archiveMD5 section)`（本版该段为空 → `md5(b"")` = `d41d8cd98f00b204e9800998ecf8427e`）
   - `md5(整个文件去掉最后这 16 字节)` ← 注意：**含前两个 md5**
5. **每个条目的 crc32** 用 zlib：`zlib.crc32(data) & 0xFFFFFFFF`

> 校验小技巧：拿**没改过**的 vpk 走一遍"读→重写"，若字节完全一致，说明打包器是对的（我们的实现就是这样验的）。
>
> 如果你不想自己写封包器：本交付里的 `03_改人机名字_参考脚本.py` 已经内建了完整读写实现，可以直接跑。

## 四、写完必须自检（4 条）

1. **条目数不变**（本版 7 个），且 `botprofile.db` 之外的 6 个 kv3 **逐字节没变**；
2. `botprofile.db` 解码为 UTF-8 无异常，档案数 = 期望值（本版 1711 + 追加 258 = 1969）；
3. 每个档案的名字都能在清单里找到，且**顺序与清单一致**；
4. 用游戏/工具重新读一遍 vpk 不报错（我们另用独立实现复核过：4 个 vpk 全部 `顺序与清单一致=True`）。

## 五、坑（务必知道）

1. **别改别的条目**：`scripts/ai/**/bt_*.kv3` 是 AI 行为树，和名字无关。
2. **Steam 会还原**：`client.dll`、`pak01_*.vpk` 这类被 Steam 托管的文件，校验/更新时会被重新下载；而 `overrides/` 是模组自己的目录，一般不动它——但**模组更新/面板"保存设置"会覆盖**。
3. **面板会覆盖**：那个 panel 工具的难度选择就是把 `overrides/{Low,Medium,High}/botprofile.vpk` **复制成** `overrides/botprofile.vpk`。所以：
   - 改**包**（zip）最稳：以后每次用新包覆盖都自带中文名；
   - 若只改游戏目录，改完别再用面板切换难度，否则会被覆盖回去。
4. **别只改一份**：root、High、Medium、Low 四份都要改（外加裸露的 `botprofile.db` 如果有）。
5. **行尾/编码**：保持 UTF-8 无 BOM、LF；不要引入 CRLF（本版原文件是 LF）。
6. **外部分片的 VPK 不支持**：本版是内联包（`0x7FFF`）；如果以后 vpk 出现 `archiveIndex != 0x7FFF`，需要按分片 `pak01_0XX.vpk` 读写，参考脚本会直接报错提示，别硬改。
7. **生效条件**：改完要**重启 CS2**（vpk 在启动时挂载）。

参考脚本用法（**不会动任何你没指定的文件**）：

```bat
:: 只看现状（不改）

:: 改游戏目录里的 4 份（每份自动 .bak 备份）
python 03_改人机名字_参考脚本.py --apply

:: 改指定目录
python 03_改人机名字_参考脚本.py --apply --dir "D:\...\game\csgo\overrides"

:: 直接改安装包，产出 xxx_中文名.zip（推荐：以后更新包也自带中文名）
python 03_改人机名字_参考脚本.py --apply --zip "C:\Users\ASUS\Downloads\CS2BotImprover.zip"
```

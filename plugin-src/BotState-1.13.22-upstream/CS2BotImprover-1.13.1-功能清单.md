# CS2 Bot Improver 整合包功能清单

**Windows 整合包 · Smarter-Bot 1.13.1 · 2026 年 11 月 19 日**

这份整合包包含原版 CS2 Bot Improver、Claude 交接时已有的人机增强，以及后续完成的爆破走位、难度、回防和闪光修复。下文按三个阶段区分，方便看出哪些功能原来就有，哪些是后来加上或重做的。

## 原版整合包已有

- **人机模式和启动面板**：Windows `Panel.exe` 可切换人机模式和普通模式；保留原包的游戏规则配置、命令入口和两种模式所需的 `gameinfo.gi`。
- **三档难度和人机个性**：简单、普通、困难三档，职业选手风格的人机配置、随机名字、购买和经济规则，以及刀具、手套、武器皮肤、探员等装饰功能。
- **基础战斗和道具**：瞄准、视野、扫射和甩狙调整；按战况使用烟雾弹、闪光弹、手雷和燃烧弹。原版 Smarter-Bot 已有自定义视野、基础闪光感知、门口及卡点处理、换弹中断和假拆等机制。

## Claude 交接时已有的增强（1.10.6）

以下内容以交接源码为准。原版已有的机制若在这阶段被扩展，按扩展部分列出。

| 方面 | 已有功能 |
| --- | --- |
| 首枪反应 | 新看到敌人时先转向和瞄准，稍后再开火。延迟会结合距离、转身幅度、是否预瞄同一人、烟雾和近期受伤等情境。 |
| 对枪与探身 | 对枪加入横移、变向和侧步，穿插停枪射击；长时间架角会触发探身、缩回或小幅换位。它们是后续持续走位的基础。 |
| 移动和切枪 | 赶路时切刀；看到敌人、听到附近动静或有近距离威胁时切回枪。限制空地乱跳，保留翻障碍、过落差和脱困需要的跳跃。 |
| 烟雾和队友报点 | 遇烟可等待、绕路、藏烟或穿烟；有受伤方向或最后接触位置时，偶尔短扫烟雾。队友只收到大概位置并据此查看。 |
| 背闪和中闪动作 | 区分自己扔的闪、队友的闪和飞行中看见的闪，按情境尝试背闪；中闪后可后撤、短暂盲扫或蹲避。 |
| T 方进攻 | 有默认控图、分路、抱团、慢打、集合进点、假打、接触进攻等计划。可按人数、接触情况和剩余时间调整，分配绕后或断后角色。 |
| CT 方站位 | 有转点、支援、空点补位和分散抱团逻辑。某些经济局会赌点。 |
| 掉包分工 | T 分出回收 C4 和掩护的人机；CT 确认掉包后可守包。拾回 C4 后继续原有进攻安排。 |
| 调试 | 新增 `css_smartbot_status` 和 `css_smartbot_debug`，可看插件状态、战术计划和角色安排。 |

## 后续新增与修复（1.11.0 至 1.13.0）

这几版重点调整爆破模式。原整合包包含的其他玩法仍在，死斗没有套用下列爆破专用的对枪和守点逻辑。

| 方面 | 当前行为 |
| --- | --- |
| 三档反应 | 识别原来选中的简单、普通或困难配置，并分别调整首次开火延迟。缩小简单和普通之间的断层；预瞄同一名敌人和突然看到新敌人分开处理。可看实测首枪延迟的分位数。 |
| 持续对枪走位 | 取消旧的“原地减速、原地射击”两个连续阶段。对枪在大拉、短横移、低速点射、换边和斜撤间衔接；根据实际速度和位移判断，撞墙时先找另一侧或后撤。 |
| 蹲拉 | 先站着沿一侧加速，有实际横移和速度后才压蹲。蹲下后继续沿同一方向移动；有足够时间和位移、且另一侧路线安全时，再保持蹲姿换边。被挡住或失去推进时起身换动作。 |
| 步枪跑打 | 步枪优先在低速移动窗口短点射，限制高速移动或腾空时的开火。近距离冲锋枪和霰弹枪仍可边走边打；狙击手可在开枪后退回。 |
| 击杀后衔接 | 清掉上一次对枪的走位、蹲伏和开火限制，立即应对下一个目标；没有新目标时，可横移查看另一条角度、退回掩体或交还给寻路。 |
| 守点探身和换位 | 通常站姿探身、缩回，几轮后换一个角度。站姿 Peek、蹲姿架枪时沿掩体移动、蹲姿推进按 **98∶8∶14** 的相对权重选择，走不通时会换方案。短暂观察后就接动作；蹲推卡住会起身。 |
| 脱困 | 根据实际移动意图和位移识别卡点，优先绕开，再重算路线；只有确认前方、头顶和落点合适才做一次蹲跳，抑制在原地反复跳。 |
| 掉人支援 | 下包前，一点被敌方击杀、另一点至少有两名守军且有人能抽身时，首次有 **60%** 概率派最近的空闲人机支援。同一点 **8 秒**内再掉人时提高到 **85%**，并至少留一人守另一点。看到 C4 或确认进攻时会按更强的情报处理。 |
| 下包后回防 | 下包后持续按实际 C4 位置安排领拆与支援，考虑距离、拆弹钳和剩余时间。交火、闪光和脱困优先；结束后能补上路线，停滞时重新尝试，领拆无法赶到时可换人。支援去周边，避免全挤到炸弹旁。 |
| 短闪和背闪回转 | 游戏判定实际受闪后，按时长暂时打断开火，侧闪等短闪也会有反应。背闪前记住朝向，爆炸后用三档统一的速度转回。多颗闪分别处理，较短的闪不会提前结束还在生效的长闪。遮挡和受闪强度仍按游戏判定。 |
| 运行修复 | 使用实际玩家槽位，修复从主菜单进图后人机遍历可能不全的问题。视角、开火和走位控制会在死亡、接管、回合切换、换图或卸载时释放。 |

## 安装与查看

- **整合包布局**：`addons/`、`cfg/`、`overrides/`、`backup/`、`gameinfo.gi` 和 `Panel.exe` 位于压缩包顶层。游戏文件的安装目录是 CS2 的 `game/csgo`，通过 `Panel.exe` 选择人机模式启动。整合包默认 **普通**，保留简单、普通、困难三个预设。
- **确认加载**：重开 CS2 进爆破图，打开控制台输入 `css_smartbot_status`，应看到 `v1.13.0`。`tier` 为难度；`ctRotate` 和 `retake` 是转点和回防下令计数；`guardPeeks` 是探身计数；`flashReturned` 和 `flashInterrupts` 分别显示回转完成和受闪开火中断记录。
- **看具体决策**：`css_smartbot_debug` 切换战术日志；`css_botstate_flashdebug 1` 开启闪光日志，`css_botstate_flashdebug 0` 关闭。`css_bot_fov status` 是原有的视野状态指令。
- **对应源码**：`addons/counterstrikesharp/source/BotState/` 附本次 1.13.0 的项目源码和许可。实际加载的插件位于 `addons/counterstrikesharp/plugins/BotState/`。

1.11.0 曾在本机 Dust II 验证实际蹲姿、探身返回和无交火条件下跨点完成拆包。当前的 1.13.0 已通过编译，整合包检查的是文件完整性；1.12.0 和 1.13.0 的最终实战手感留给你验证。

## 1.13.1 见敌移动衔接

- 人机移动中首次看到敌人时，短暂延续原方向并接入横移，减少立即减速造成的停顿。道路受阻时仍会尝试其他安全方向。
- 静止时看到敌人优先开始移动。首枪反应延迟与射击速度限制继续生效。
- 持刀、下包拆包、背闪和梯子场景继续使用原有控制逻辑。
